?Cómo usar la app

1. Empezar la auditoría: pulsa "Nueva auditoría" desde la pantalla principal. La fecha y la hora de inicio se rellenan solas.

2. Marcar cada ítem: selecciona SÍ, NO o N/A. Si encuentras una incidencia, añade la observación y adjunta una o varias fotos pulsando el botón "+".

3. Plan de acción: al final hay un campo grande para anotar los puntos de mejora y la firma con el dedo.

4. Guardar: pulsa "Guardar" en cualquier momento. Si cierras la app, lo retomas desde el Histórico.

5. Exportar PDF: el botón "Generar PDF" crea el informe con el formato de Cor Outsourcing, listo para imprimir, enviar por WhatsApp o email.

↓Instalar como app

Android (Chrome): abre el menú (⋮) → "Instalar aplicación" / "Añadir a la pantalla de inicio".

iPhone (Safari): botón Compartir → "Añadir a pantalla de inicio".

Una vez instalada funciona sin internet y se abre como una app normal.

⎋Cerrar sesión

Si necesitas que la app vuelva a pedir la contraseña, pulsa el botón. Esto no borra las auditorías guardadas, solo el acceso.
